# CodeAlpha Internship Tasks

Welcome to my repository for the CodeAlpha Artificial Intelligence Internship. This repository contains my submissions for the required tasks.

## 📌 Projects Included

1. **[Language Translation Tool](./CodeAlpha_LanguageTranslation)**
   A web-based translation application built with Streamlit and the Google Translate API. It allows users to translate text between various languages instantly.

2. **[Chatbot for FAQs](./CodeAlpha_Chatbot)**
   An intelligent command-line chatbot designed to answer Frequently Asked Questions about Blockchain. It uses NLP techniques (NLTK) and Cosine Similarity (scikit-learn) to find the best-matching answers to user queries.

3. **[Object Detection and Tracking](./CodeAlpha_ObjectDetection)**
   A real-time computer vision application using OpenCV and YOLOv3. It captures live video from a webcam, detects objects frame-by-frame, and tracks them using a custom Euclidean distance-based tracking algorithm.

## 🚀 Status
All three tasks have been successfully completed and meet the internship requirements.
